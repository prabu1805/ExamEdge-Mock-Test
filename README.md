 🚀 ExamEdge – Online Mock Test Platform

ExamEdge is a **modern online mock test platform** built using **React and Node.js** that simulates a real competitive exam environment.
It allows users to attempt quizzes with a timer, navigate between questions, and view results with a leaderboard.

 ✨ Features

✅ **User Login** – Enter your name and start the test
⏱ **Exam Timer** – Countdown timer for realistic test experience
🧭 **Question Navigation Panel** – Jump to any question instantly
📝 **Multiple Choice Questions (MCQs)**
📊 **Instant Result Calculation**
🏆 **Leaderboard** – Displays top scores
🎨 **Attractive UI Design** – Clean and modern interface

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/prabu1805/ExamEdge-Mock-Test.git
```

---

### 2️⃣ Install dependencies

Frontend:

```
cd frontend
npm install
```

Backend:

```
cd backend
npm install
```

---

### 3️⃣ Run the project

Start backend server:

```
node server.js
```

Start frontend:

```
npm start
```

The app will run on:

```
http://localhost:3000
```
